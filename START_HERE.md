# Progressors MAX — готовая замена проекта

Это полный проект на базе предоставленного тобой `Progressors_MAX_ready.zip`, но с обновлённым UI/UX.

## Что делать

1. Полностью удали старую папку проекта `hackatonMAX`.
2. Распакуй содержимое этого ZIP.
3. В корне проекта создай `.env` по образцу `.env.example`.
4. Перенеси в `.env` свои текущие значения Render/MAX/Groq. Секреты в ZIP не включены.
5. В `miniapp` выполни:

```powershell
npm ci
npm run build
```

6. Backend запускай как раньше через Docker/Render.
7. Mini App деплой на тот же домен/сервис, который сейчас указан в `MINIAPP_URL`.

## Что изменено по дизайну

- новый более аккуратный dark UI;
- pink/violet фирменный акцент без чрезмерного свечения;
- мобильная нижняя навигация;
- desktop sidebar начиная с 900px;
- dashboard больше не зажат в 480px на десктопе;
- safe-area для iOS/Android;
- поддержка `prefers-reduced-motion`;
- единые карточки, кнопки, границы и типографика;
- существующие страницы, данные и роуты сохранены.

## Важно

В архиве намеренно отсутствует `.env`. Не вставляй секреты в GitHub или ZIP для жюри.

`npm run build` нужно выполнять уже после `npm ci` в твоём окружении. В текущем рабочем контейнере установка npm-зависимостей не завершилась из-за ограничения времени/окружения, поэтому результат production-сборки здесь не заявляется как проверенный.
