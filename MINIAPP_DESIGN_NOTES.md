# Progressors MAX — polished build

This archive is a complete replacement project based on the supplied Progressors MAX codebase.

## What was polished
- Dark premium UI with restrained pink/violet accents.
- Mobile-first bottom navigation with safe-area support.
- Desktop layout with persistent left navigation at 900px+.
- Wider dashboard on desktop instead of a forced 480px phone layout.
- Consistent cards, buttons, borders, typography and spacing.
- Reduced excessive glow/animation while keeping the product identity.
- Reduced-motion accessibility support.
- Kept the existing routes, learning data and functionality intact.
- Removed `.env` from the archive so secrets are not shipped in the replacement ZIP.

## Important
Copy your existing environment variables into a new `.env` locally / Render environment. Do not commit `.env`.
